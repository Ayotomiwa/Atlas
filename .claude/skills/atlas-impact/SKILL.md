# atlas-impact

Resolve the starting concept, traverse page relationships and relevant generated maps including reverse views, then bucket results as **known affected**, **possibly affected**, and **unknown or not covered**. Cite evidence. Never claim “not affected” merely because an edge is absent. Never write files.
