# atlas-humanize

Read the shared clear-writing, persistence, and runtime contracts plus `references/atlas-prose.md`. This workflow is for persisted Atlas prose, not ordinary answers.

Resolve the requested path or diff and read its governing README/template and minimal semantic contracts. Inventory generated blocks, parser-owned headings, tables, links, commands, controlled terms, and material claims. Separate readability problems from semantic contradictions or unsupported claims; route bounded semantic inspection to `atlas-lint-analyst` when useful.

Never edit generated content or committed staging evidence. Show one scope-bound preview covering proposed wording, protected content, excluded semantic findings, validation, branch, and commit. After approval, apply only meaning-preserving prose edits. Preserve frontmatter, facts, certainty, scope, evidence, IDs, links, commands, tables, parser interfaces, safety language, and unknowns.

Review the diff claim by claim, run Atlas lint plus focused checks required by the changed surface, and create one exact-path local commit. Report changes, protected content, unresolved semantic findings, validation, branch, and commit. Never push, merge, approve, or publish.
