# atlas-stage

Read the shared human-intent, persistence-approval, runtime, provenance, curation-safety and clear-writing contracts plus staging root policy and the selected bucket README/template/index. This is the write step behind **Teach Atlas**. Do not delegate.

1. A direct request needs the shared concrete preview and scope-bound approval. An internal handoff reuses approval only when its exact claims, files and targets still match. Re-preview material scope changes instead of asking twice for an unchanged one.
2. Build or verify the ephemeral duplicate snapshot defined by the shared handoff contract. Use the full staging, typed curated `find`, exact-route and relevant-index search for a direct request, incomplete snapshot or changed searched surface. Otherwise recheck only output-path uniqueness, exact qualified-question references, known duplicates and selected-target identity. Never persist the snapshot or silently resolve ambiguity.
3. Read the applicable taxonomy, compiler contract and destination contract, then perform the shared branch/HEAD/content-clean recheck. If those checks or duplicate discovery materially change the proposed claims, files, targets, evidence boundary, destructive effects or checkpoint range, return a revised preview. Choose the primary-fact bucket and split only independent boundaries. Route broad investigation to repository onboarding and incremental merged-default-branch ranges to `atlas-stage-changes`.
4. Allocate a deterministic staging ID and draft once with the clear-writing contract: capture one coherent curation-ready record with readable meaning, precise source references, causal boundaries, known/possible states, gaps and suggested targets. For question-derived evidence, cite every originating qualified `<record-id>#<question-id>` in the body.
5. Flag sensitive artifacts without values. Never revise committed evidence or write curated/generated files. Validate, then create the shared exact-path local commit on the selected feature branch.
6. Use the shared plain-language completion summary; expose the branch/commit, record ID, lifecycle and duplicate routes as audit detail.
