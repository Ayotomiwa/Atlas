# atlas-curate

Read shared human-intent/persistence/runtime/provenance/handoff and curation-safety contracts. This is **Curate Atlas**. Successful reconciliation and independent review produce authoritative `status: curated` knowledge; merge only distributes and audits it.

1. Default the active queue to the current repository/domain/ID/topic; show the package-wide queue only when requested. Read the shared authoring prerequisites, source/target contracts and semantic preflight, but do not mark records `curating` before approval.
2. Build internal decisions with exact IDs/find. Staging should allow curation without broad product rediscovery: inspect exact cited product evidence only, while browsing Atlas broadly for targets/links. Newly required product facts must be staged first and cause a revised preview.
3. Complete Git preflight: reuse/state the current feature branch, asking for a suggested/custom branch only when necessary. Record starting `HEAD`, lint and freshness baselines. Ask one consolidated clarification round, then preview branch/local commits, statuses, pages/claims, generation, unknowns and review. After approval re-check queue, branch, `HEAD`, actual content-clean state and scope; changed scope requires a new preview.
4. Pass the exact scope/matrix to `atlas-curator`, inspect its diff, and create the exact-path checkpoint commit before repair. Own aggregate lint classification, up to two in-scope meaning-preserving repair passes, path verification, rebuild/check and the validated commit. Current/changed-shared/new/unexplained issues block; unchanged unrelated baseline issues are advisory and may defer freshness.
5. Review immutable starting-to-proposal commits independently with the same clean `HEAD` before/after. Commit supported fixes and re-review the full range. After clean review, apply approved terminal statuses, checkpoint/generated effects and exact finalization commit. Semantic changes require a revised preview and full review. Report Current work, Scope validation, Generated freshness and Package health before audit traceability.

Create only previewed local commits on the selected feature branch. Never push, merge, force-update, publish, bypass independent review or hand-edit generated artifacts.
