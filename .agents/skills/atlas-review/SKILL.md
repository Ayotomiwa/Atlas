# atlas-review

Read shared human-intent/runtime/provenance/handoff contracts. This read-only workflow is for audits, external diffs and second opinions; normal curation invokes independent review internally. Resolve original evidence and affected surfaces, then delegate to `atlas-reviewer`.

Report blockers, major/minor findings, open decisions, validation and residual risk. Cite exact changed paths/lines and original evidence for every finding, including the staging -> curated -> generated route when relevant. Never edit, approve, merge, commit or publish.
