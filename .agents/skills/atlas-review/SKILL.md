# atlas-review

Read shared runtime/provenance/handoff contracts. Resolve original evidence and affected surfaces, then delegate independent inspection to `atlas-reviewer`.

Report blockers, major/minor findings, open decisions, validation and residual risk. Cite exact changed paths/lines and original evidence for every finding, including the staging -> curated -> generated route when relevant. Never edit, approve, merge, commit or publish.
