# atlas-discover

Read `../_shared/runtime.md`, `answer-provenance.md` and `agent-handoffs.md`. This is read-only.

1. Bypass Atlas when a simple answer is fully visible in supplied local source. Otherwise start with `atlas_query.py context <current-path>` and preserve candidate ambiguity.
2. Use exact IDs/maps/indexes after context. Handle small direct lookups locally; delegate ambiguity, synthesis, traversal or substantial fallback to `atlas-discovery-analyst`.
3. Open curated pages for meaning/evidence. When coverage ends, disclose the boundary and inspect bounded product source.
4. Choose the clearest prose/table/route/Mermaid presentation. Cite every material claim and disclose all answer-bearing Atlas/source hops.
