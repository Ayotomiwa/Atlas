# atlas-evaluate

Resolve and validate Atlas, then read `evaluation/README.md`, `evaluation/rubric.json`, and `references/protocol.md`. Require one explicit sealed destination outside Atlas; keep every fixture, persona, question, truth, answer, telemetry, result, worktree, and run output there.

- `prepare`: run `scripts/atlas_eval.py prepare`; the fixture preparer records provenance/licence/de-branding, freezes realistic cold and incremental source history, and creates canonical paired inputs, judge-only truth, and the fixture, tool-policy, model-config, and Atlas-snapshot manifests. Authors receive only source worktrees and an authoring persona, never questions, truth, answers, scores, or category quotas.
- `run`: use disposable worktrees. The simulated user completes governed onboarding, staging, curation, validation, and independent review before snapshot export. Then fresh roles answer the same frozen questions under required `manifests/tool-policy.json`, which fixes exact tools, budgets/timeboxes, and answer/citation conventions. If it is absent, unreadable, or omits any of those fields for the role, stop before answering and report the protocol failure; never improvise. The Atlas interrogator receives only the frozen Atlas snapshot and question, answers only from that snapshot, and never uses product source or bounded source fallback; it does not execute fixture/source/snapshot code unless the tool policy explicitly permits it. The control receives only the raw fixture (including hidden files and relevant Git history) and question, never Atlas, managed instructions, network, or a persistent scratch index; its notes remain transient and question-local. Write only the run-defined answer plus separate observable-or-`null` telemetry for each arm. After both arms and every protected input exist, run `python scripts/atlas_eval.py freeze <run-root>`, capture the manifest SHA-256 outside protected/mutable run state, retain it separately, and run `python scripts/atlas_eval.py verify-freeze <run-root> --freeze-digest <retained-digest>` before truth is readable.
- `score`: only the independent judge reads frozen truth, and only after receiving the separately retained digest and successfully running `python scripts/atlas_eval.py verify-freeze <run-root> --freeze-digest <retained-digest>`. Without that digest it stops before truth. It verifies citations, assigns only question judgments and evidence-bearing G1-G8, never enters derived M5/M6 summaries, and never edits protected artifacts. It verifies again with the same command before returning, then runs `python scripts/atlas_eval.py validate <run-root>/results/result.json --freeze-digest <retained-digest>` and `python scripts/atlas_eval.py score <run-root>/results/result.json --freeze-digest <retained-digest>`. A non-standard result path adds `--run-root <run-root>` to validate/score. Any recorded Atlas source access or control Atlas access forces `Not ready`.

Preserve the legacy v1 path explicitly: `atlas-evaluation-run/1.0` uses its answer-only freeze and `atlas-evaluation-result/1.0` without gaining v2 master-freeze guarantees. Fixture-only commits are permitted only in the explicit external destination. Never publish or approve Atlas knowledge, contaminate real Atlas with fixture content, estimate telemetry, or let an evaluated role grade itself.
