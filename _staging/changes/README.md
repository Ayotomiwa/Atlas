# Changes staging

## Purpose
Reusable context discovered during a logical code/change investigation.

## Belongs here
Evidence that can be sourced, uncertainty, possible relationships and reviewer questions relevant to this bucket.

## Does not belong here
Authoritative curated claims, secrets, unsupported production facts, or content better represented in another staging bucket.

Use `_template.md`. Do not create a bucket-level `index.md` in V1.
